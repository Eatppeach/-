二、核心函数调用关系 — 实时对话全链路

从用户输入 → 安全检测 → 脱敏 → SSE流式转发 → 输出扫描 的完整调用链

sequenceDiagram participant UI as chat.html
sendMessage() participant API as app.py
api_chat_proxy() participant GW as proxy_gateway.py
SecurityGateway participant RE as recognition_engine.py
RecognitionEngine participant DE as desensitization_engine.py
DesensitizationEngine participant DB as database.py
audit_logs participant LLM as 上游 LLM API Note over UI,LLM: ═══ 阶段一：请求安全预处理 ═══ UI->>API: POST /api/gateway/chat
{message, history, stream:true} API->>GW: process_request(user_input, ...) GW->>RE: scan(text, client_ip, user_id) RE->>RE: _is_whitelisted(text, ip, uid) alt 命中白名单 RE-->>GW: {whitelisted:true} GW-->>API: {action:"passed"} else 未命中白名单 RE->>RE: 遍历 _compiled_rules
正则匹配 + 关键词匹配 RE-->>GW: {matches[], match_count, highest_level} end GW->>GW: _check_block(scan_result) GW->>GW: _evaluate_condition(condition, scan_result) alt 硬阻断 (hard) GW->>DB: add_audit_log(action="blocked") GW-->>API: {action:"blocked", block_level:"hard"} API-->>UI: 403 + 阻断信息 else 软阻断 (soft) 或 静默 (silent) GW->>DE: desensitize(text, matches) DE->>DE: _find_policy(rule_name) DE->>DE: _apply_desensitization(text, method, config) alt method=mask DE->>DE: _mask(text, {keep_prefix, keep_suffix}) else method=encrypt DE->>DE: _encrypt(text, config) else method=hash DE->>DE: _hash(text, config) else method=generalize DE->>DE: _generalize(text, config) end DE-->>GW: 脱敏后文本 GW->>DB: add_audit_log(action="desensitized") GW-->>API: {action:"desensitized", processed_input} else 无敏感信息 GW->>DB: add_audit_log(action="passed") GW-->>API: {action:"passed", processed_input} end Note over UI,LLM: ═══ 阶段二：SSE 流式转发 ═══ API->>GW: stream_llm_response(processed_input, upstream_url, ...) GW->>LLM: POST with stream=True
{model, messages, stream:true} loop 逐行读取 SSE 流 LLM-->>GW: data: {"choices":[{"delta":{"content":"xxx"}}]} GW-->>API: yield "data: {...}\n" (透传，不阻塞) API-->>UI: SSE chunk UI->>UI: 解析 delta.content
逐字更新 DOM 实现打字效果 GW->>GW: 静默累积 accumulated += content end Note over UI,LLM: ═══ 阶段三：输出安全扫描 ═══ LLM-->>GW: data: [DONE] GW->>GW: process_output(accumulated) GW->>RE: scan(accumulated) — 扫描模型输出 RE-->>GW: scan_result alt 模型输出含敏感信息 GW->>DE: desensitize(accumulated, matches) DE-->>GW: 脱敏后输出 GW-->>API: yield warning API-->>UI: "⚠ 模型输出中检测到敏感信息" end GW-->>API: yield "data: [DONE]\n" API-->>UI: 流结束
